# 自行构建与修改

本项目纯分享、不维护。此文档记录当前实现和修改时需要保留的约束。

## 环境与入口

在 Windows 上使用 Windows PowerShell 和 .NET Framework 4.x 自带的 C# 编译器。源码保持该编译器支持的语法，不依赖 .NET SDK、NuGet 或第三方运行库。

```powershell
# 先从托盘退出本工具，避免覆盖正在运行的 EXE。
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

`build.ps1` 生成 `dist/IDMClose.exe`、测试程序和说明副本。`Program.cs` 包含应用实现，`Tests.cs` 为无第三方测试框架的可执行测试。运行正式程序不弹出主窗口；`--inspect` 单独生成只读报告并打开记事本。

## 识别与关闭链路

1. `TrayApp` 持有消息循环、托盘、显示／名称变化事件钩子和每秒扫描计时器。扫描在后台执行，同一时刻只运行一轮；暂停前的扫描结果不能在恢复后继续执行关闭。
2. `Scanner` 先限制到 `IDMan` 进程所属顶层窗口。依次读取原生窗口文字、内嵌网页正文，仍不匹配时尝试 UI Automation。
3. 所有文字通过 `Rules.Matches` 判断：忽略空白，同时包含 `Internet Download Manager` 与 `免费试用已经到期`。无法确认的窗口保留，不使用坐标、窗口大小或空标题猜测。
4. `Closer` 在发送前复核窗口句柄、所属进程、线程、窗口类和可见性，向目标发送 `WM_CLOSE`。销毁或不可见后才累计；未响应会报错，至多发送三次，间隔至少五秒，使用单调时钟计时。
5. 退出时停止计时器并解除钩子，释放托盘资源。命名互斥体限制正式工具为单实例。

## 内嵌网页是必要的读取路径

真实到期弹窗是空标题的 `#32770` 对话框，其子窗口包括 `Shell Embedding`、`Shell DocObject View`、`Internet Explorer_Server`。原生控件文字为空，原来的 UI Automation 路径也没有获得匹配内容。

`HtmlReader` 向网页子窗口发送 `WM_HTML_GETOBJECT`，使用 `ObjectFromLresult` 获取 `IHTMLDocument2`，只读取 `body.innerText`。COM 对象在独立的 STA 后台线程中创建、使用并释放，不跨线程共享，也不执行网页按钮或脚本。

网页读取和 UI Automation 各限制为一个未完成的后台任务，并有调用方等待上限。异常提供程序卡住时跳过对应读取路径；后台线程不阻止退出。超时后的结果直接丢弃，避免把旧文字用于已复用的窗口句柄。读取上限和重试间隔见实现，不能为了“更容易匹配”去掉保护。

## 测试与验收

`build.ps1 -Test` 执行文案规则、自启项恢复、单实例、原生窗口、内嵌网页、关闭确认／有限重试、暂停恢复，以及停用兜底计时器后的事件响应测试。当前分享快照通过 48 项断言；测试失败以进程非零退出码报告。

模拟器复制为临时 `IDMan.exe`，用该进程的 PID 限制被测扫描范围，窗口放到屏幕外。不要去掉 PID 隔离，否则测试可能影响真实 IDM。测试会临时改写当前用户的工具启动项，并通过 `finally` 恢复；不要强制中断测试。

模拟测试不能替代实机验证。遇到真实故障时，先暂停工具保留弹窗，运行 `--inspect`，核对窗口结构、可读取文字、匹配结果及错误日志。修复后验证同一个窗口是否已不可见，并单独检查正常窗口和下载任务；不要仅根据进程仍在就宣称下载已验证。

## 数据与发布边界

运行数据保存在 `%LOCALAPPDATA%\IDMClose`；仅自启选项写入当前用户的 Run 启动项。诊断模式只读窗口，但会写本地报告，其中可能包含下载相关信息；排除 Edit 控件不等于报告完全不含敏感信息。

源码提交不包含 EXE、日志、诊断报告、用户数据或凭据。提交前检查 `git status --short`、`git diff --cached` 和 `git diff --check`。没有自动更新、发布流水线或持续兼容性承诺。
